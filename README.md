# You — Identity and Access Management

Cross-app identity, authentication, authorization, and user settings platform. Every service (Sockeet, future apps) delegates user management to You.

## Architecture

```
You ──── auth, users, roles, 2FA, billing (future)
   │
   ├── Sockeet ─── validates You-issued JWTs
   ├── (future app) ─── same pattern
   └── User-facing apps ─── login/logout via You's API
```

Apps never touch You's database. Communication goes through:
- **REST** — `POST /api/login`, `POST /api/login/verify`, `DELETE /api/logout`
- **Erlang distribution** — token validation, user lookup, revocation via `You.IAM.Server`
- **GraphQL** (future) — user profile, settings, teams

## Stack

| Layer | Choice |
|-------|--------|
| Runtime | Elixir 1.19.5 / Erlang 29.0.1 |
| Web | Phoenix 1.8.7 / Bandit |
| Database | SQLite via ecto_sqlite3 / exqlite |
| Auth foundation | `mix phx.gen.auth` |
| JWT | Ed25519 via jose |
| 2FA | TOTP via nimble_totp |
| Password hashing | bcrypt_elixir |

## API

### Authentication

```
POST /api/login
Content-Type: application/json

{"email": "user@example.com", "password": "hello world!"}
```

**Response** (no 2FA):
```json
{"jwt": "eyJhbGciOiJFZERTQSIs..."}
```

**Response** (2FA enabled):
```json
{"status": "2fa_required", "pre_auth_token": "eyJhbGciOiJFZERTQSIs..."}
```

```
POST /api/login/verify
Content-Type: application/json

{"pre_auth_token": "...", "totp_code": "123456"}
```

```json
{"jwt": "eyJhbGciOiJFZERTQSIs..."}
```

```
DELETE /api/logout
Authorization: Bearer <jwt>
```

### Sessions (HTML)

Generated by `phx.gen.auth` — registration, login, settings, magic link available at `/users/*`.

## Erlang Distribution

Consumer apps (Sockeet) connect as Elixir nodes and call `You.IAM.Server`:

```elixir
# On a connected node:
GenServer.call({You.IAM.Server, :"you@host"}, {:verify_token, jwt})
# => {:ok, %{user_id: 1, email: "...", role: "user"}}
```

See [docs/adr/0002-erlang-distribution.md](docs/adr/0002-erlang-distribution.md).
